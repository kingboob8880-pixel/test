  message: 'Сообщение',

## 📱 PWA возможности

### Установка на устройство
1. Пользователь заходит на сайт
2. Через 5 секунд появляется prompt установки
3. При нажатии "Установить" — добавляется на главный экран
4. Работает как нативное приложение (без адресной строки)

### Офлайн режим
- При потере соединения показывается жёлтый индикатор
- Все данные доступны из IndexedDB
- Изменения сохраняются локально
- При появлении сети — автоматическая синхронизация

### Push уведомления
- Требуют разрешения пользователя
- Работают даже при закрытом приложении (через SW)
- Поддерживают действия (кнопки)

## 🚀 Производительность

### Кэширование
- **Статические ресурсы:** Кэшируются при установке SW
- **Динамические данные:** Network First → Cache → Fallback
- **Размер кэша:** ~500 KB (все JS/CSS/Data файлы)

### Оптимизация
- **Debounce поиска:** 150ms
- **Ленивая индексация:** При открытии поиска
- **Анимации:** CSS transitions (GPU accelerated)
