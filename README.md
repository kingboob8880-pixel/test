## Быстрый старт

1. Откройте `index.html` в браузере
2. Приложение работает офлайн после первой загрузки
3. Для AI-диагностики настройте DeepSeek API ключ в настройках

## Возможности

- ✅ Приём новых пациентов (3-шаговый мастер)
- ✅ Диагностика (локальная + AI + ручная)
- ✅ Автоматическая сборка планов лечения
- ✅ База пациентов с мониторингом
- ✅ Анкеты и история сеансов
- ✅ Заключения и документы
- ✅ Календарь визитов
- ✅ Библиотека программ
- ✅ 10 тем оформления
- ✅ PWA с офлайн-работой
- ✅ Экспорт/импорт данных
- ✅ Интеграция с GitHub

## Методика

Система построена на исламской методике рукьи согласно Сунне, без медицинских диагнозов, с акцентом на духовное лечение по методу Абу Мухаммада.

## Лицензия

Использование для личных и профессиональных целей специалиста по рукье.
