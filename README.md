# RUKYA PRO — PWA Система для специалистов по рукье

> **Ash-Shifa · Абу Мухаммад** — профессиональная система для ведения пациентов, диагностики духовных недугов и создания планов лечения.

## Возможности

### ✅ Реализовано

1. **Дашборд «Сегодня»** — KPI карточки, статистика, список активных пациентов
2. **Мастер нового приёма** — 3 шага: пациент → диагностика → план
3. **База пациентов** — список, поиск, фильтрация, карточка пациента
4. **Диагностика** — локальная (офлайн), из JSON, AI через DeepSeek API
5. **Хранение данных** — IndexedDB, мягкое удаление, экспорт/импорт
6. **Настройки** — 10 тем оформления, размер шрифта, плотность интерфейса
7. **PWA готовность** — манифест, service worker (базовый)

### 📋 В разработке

- Полная библиотека программ лечения
- Календарь визитов
- Система заключений
- Мониторинг симптомов
- Журнал сеансов
- Анкеты пациента

## Установка и запуск

### Локальный запуск

1. Откройте `index.html` в браузере (Chrome/Firefox/Edge)
2. Или используйте локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

3. Перейдите на `http://localhost:8000`

### Установка как PWA

1. Откройте сайт в Chrome/Edge
2. Нажмите на иконку установки в адресной строке
3. Или меню → «Установить приложение»

## Настройка API ключа

Для AI-диагностики через DeepSeek:

1. Перейдите в раздел **Настройки**
2. Введите ваш API ключ DeepSeek
3. Сохраните

- `Ctrl+K` — Глобальный поиск
- `Escape` — Закрыть модальное окно

## Хранение данных

Все данные хранятся локально в браузере через IndexedDB:
- Пациенты
- Планы лечения
- Заключения
- Настройки
- История изменений

### Экспорт/Импорт базы

В разделе **Настройки** доступны функции экспорта и импорта всей базы данных в JSON формате.

## Оффлайн работа

Система работает без интернета:
- Локальная диагностика по симптомам
- Просмотр сохранённых пациентов
- Редактирование данных
- Создание планов

AI-диагностика требует подключения к интернету.
